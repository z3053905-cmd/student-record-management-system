# student-record-management-system
A C++ console application for university student records using Object-Oriented Programming (OOP), arrays, inheritance, and file handling.
## 🚀 Core Features
- **Object-Oriented Architecture:** Uses clean inheritance patterns.
- **Academic Tracking:** Leverages arrays and custom logic to manage multi-semester GPAs.
- **Data Persistence:** Automatically exports and saves student records to a secure text file (`student_records.txt`).
- **Clean Console UI:** Formatted output designed for optimal readability.

## 🛠️ Concepts Implemented
- **Classes & Objects** (Encapsulation of Student Data)
- **Inheritance** (Base Class `Person` -> Derived Class `Student`)
- **Arrays & Loops** (For iteration and GPA storage)
- **File Handling** (`ofstream` for text database creation)

## 📂 File Structure
- `main.cpp`: Main source code containing the logic and classes.
- `student_records.txt`: Generated database file containing the persistent records.
